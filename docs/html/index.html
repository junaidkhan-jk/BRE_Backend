If you ever rebuild it and the page comes up blank, check that the script tag is <script src> and not type="module": browsers block ES modules over file://, and a blank page is the only symptom.

The Studio shows sample data. No Backend-for-Frontend exists yet, so the screens are served from the wireframes' own example rules and decisions. A banner says so on every screen. Nothing you see there reflects a real rule or a real decision.

What would help most as feedback

  • Rule-centric or policy-version-centric? The wireframes organise the workspace around a rule; the specification organises it around a policy version — which is what gets reviewed, signed, deployed and rolled back. The rule-centric view is friendlier to an author but has nowhere to say "live in UAT, pending approval in PROD".
  • Is the AI assistant in scope? "Compile with AI" appears in the wireframes and in no part of the specification. The button is in the UI and does nothing — there is no service behind it. Before building it: which model, hosted where, and what stops a machine-drafted credit rule reaching submission unread.
  • Is "TRL" the policy-sentence view? The editor has a TRL tab because the wireframes do. The specification has BEL, PSF and a deterministic policy-sentence renderer. If TRL means the last of those, it should be renamed.
